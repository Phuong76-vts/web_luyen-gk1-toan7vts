# Toán 7 • Ôn luyện giữa kì 1 (2026–2027)
Web tĩnh một file (index.html), không cần cài đặt hay build.

## Cách đưa lên mạng (GitHub + Vercel)
1. Vào github.com → New repository → đặt tên `toan7-on-giua-ki-1` → Create.
2. Bấm "uploading an existing file" → kéo thả 3 file: `index.html`, `vercel.json`, `.gitignore` → Commit changes.
3. Vào vercel.com → Add New → Project → chọn repo vừa tạo → Deploy (giữ mặc định, không chọn framework).
4. Sau vài chục giây có địa chỉ dạng `toan7-on-giua-ki-1.vercel.app` → gửi cho học sinh (hoặc tạo mã QR).

## Cập nhật sau này
Sửa/ghi đè `index.html` trên GitHub → Vercel tự đăng lại.

## Ghi chú
- Học sinh chơi ngay, không cần tài khoản. Biệt danh và tiến trình lưu trong trình duyệt của từng em.
- Bản nháp: cô duyệt trước khi phát cho học sinh.
- Tác giả: cô Ngô Thị Phương – Tổ trưởng Tổ KHTN, THCS Võ Thị Sáu (hiện ở đầu trang, chân trang và thẻ meta).
- Phạm vi: Số hữu tỉ · Số thực · Góc và đường thẳng song song. Cấu trúc đề: 12 nhiều lựa chọn + 2 đúng–sai + 8 trả lời ngắn + 3 tự luận, 90 phút. 30 đề đánh số + đề ngẫu nhiên.
